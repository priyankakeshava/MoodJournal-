# MoodJournal-
MoodJournal is a PHP and MySQL web application that allows users to track their daily emotions and maintain a personal journal through an interactive calendar interface.

## Project Features

### 1. Dynamic Monthly Calendar

Built using JavaScript, the application automatically generates a monthly calendar and allows users to navigate between months.

### 2. Interactive Mood Entry Modal

Users can click on any date to open a modal window where they can record their mood and write a journal entry.

### 3. Mood Tracking and Journaling

Users can select an emotion using emoji-based mood indicators and save personal notes describing their day.

### 4. Visual Calendar Representation

Saved entries are displayed directly on the calendar. Each mood is represented by a unique color and emoji, making emotional trends easy to identify at a glance.

### 5. Entry Management

Users can view, edit, and delete previously saved mood entries. Existing records are automatically loaded when a selected date already contains data.

### 6. Mood History Page

A dedicated history page displays all journal entries in chronological order, allowing users to review their emotional journey over time.

### 7. Statistics Dashboard

The application analyzes stored mood data and generates visual progress bars showing the percentage distribution of each mood category.
